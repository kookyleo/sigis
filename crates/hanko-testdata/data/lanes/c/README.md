# Lane C fixtures (difference analysis)

Generated by lane C with pyHanko 0.38.1 and pyhanko-certvalidator 0.33.0
(tag `v0.38.1`, commit `580f49498f76`). Used by `crates/hanko-diff/tests/`.

| File | Content | Generator |
| --- | --- | --- |
| `cases.json` | For each test of pyHanko's `pkgs/pyhanko/tests/test_diff_analysis.py` (pytest node id): its outcome and, in call order, every `StandardDiffPolicy.review_file` call (input file, reader strictness, base revision, FieldMDP spec, DocMDP level, policy configuration, pyHanko's verdict) and every `_load_reverse_xref_cache` result | `crates/hanko-diff/oracle/capture.sh` (pytest plugin `capture_plugin.py`) |
| `pdf/<sha>.pdf` | The input files of those calls (`<sha>` = first 24 hex digits of the SHA-256) | same |
| `model/<sha>.json` | pyHanko's cross-reference model of each file: per revision the section data (`standard`, `objstm`, `freed`, explicit references, object streams), section metadata, hybrid section, the flattened trailer and the end of the revision | same |
| `sweep.json` | pyHanko's `DEFAULT_DIFF_POLICY` verdict for every file and base revision, strict and lenient | `crates/hanko-diff/oracle/sweep.py` |

Reproduction: `crates/hanko-diff/oracle/capture.sh PYTHON PYHANKO_SRC`, then
`python crates/hanko-diff/oracle/sweep.py crates/hanko-testdata/data/lanes/c > crates/hanko-testdata/data/lanes/c/sweep.json`.
pyHanko's tests freeze time with freezegun (mostly 2020-11-01), so the
verdicts are reproducible; the signed files embed random CMS content, so
their bytes and hashes change between runs (rerun `sweep.py` after a
capture).

The input files derive from pyHanko's test data
(`crates/hanko-testdata/data/pyhanko/pdf/`) and are signed with pyHanko's
public test PKI (`crates/hanko-testdata/data/pyhanko/crypto/`). They contain
no private keys. License: MIT (`../../pyhanko/LICENSE-pyHanko`).
